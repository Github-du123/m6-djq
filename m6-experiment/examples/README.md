# Executed M4 typed API examples

These records came from actual M4 ToolSet methods running on M3-normalized fixture data.
They are not invented ledger lines, Elasticsearch responses or independent agent reports.
The backend responses are explicitly from a local fixture backend.

- `run-a`, `run-b`: fresh run IDs, ledgers and full typed/backend responses.
- `comparison/comparison.html`: open in a browser to review the table.
- `comparison/differences.json`: exact set differences.
- `comparison/REPORT_SUMMARY.md`: current-stage English summary.
- `kibana/`: generated saved objects plus import checklist, not a verified live export.

The smoke verdict is inconclusive because M5 was not involved. These examples test tool
integration and evidence traceability. They cannot establish LLM repeatability or accuracy.
No private ground truth is included. Re-freeze against your checkout before new runs.
